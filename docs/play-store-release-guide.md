## 2. 배포 키 생성 및 빌드

Google Play는 2021년 8월부터 신규 앱에 대해 **AAB(Android App Bundle)** 형식을 의무화하고 있습니다.

### 2.1 릴리스 서명 키(Keystore) 생성
서버 또는 개발 PC의 터미널에서 다음 명령으로 배포용 키스토어를 생성합니다:

```sh
keytool -genkeypair -v \
  -keystore pumsok-upload.jks \
  -alias pumsok-upload \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000
```
> [!IMPORTANT]
> 생성한 `.jks` 파일과 비밀번호는 절대 분실하지 않도록 안전한 곳(비밀번호 관리자 등)에 백업하세요.

### 2.2 `keystore.properties` 설정
프로젝트 루트 디렉터리에 `keystore.properties` 파일을 생성합니다 (이 파일은 `.gitignore`에 등록되어 커밋되지 않습니다):

```properties
storeFile=/경로/pumsok-upload.jks
storePassword=키스토어비밀번호
keyAlias=pumsok-upload
keyPassword=키비밀번호
```

> **참고**: `keystore.properties`가 없는 환경에서는 기본 `debug` 키로 서명되도록 구성되어 있어 테스트 빌드가 즉시 가능합니다.

### 2.3 AAB 번들 생성
```sh
./gradlew bundleRelease
```
- 생성 위치: `app/build/outputs/bundle/release/app-release.aab`
- 이 `.aab` 파일을 Play Console에 업로드합니다.

## 3. 스토어 등록정보 텍스트

### 3.1 앱 이름 (최대 30자)
```text
품속동화 - 부모님 목소리 동화 리더
```

### 3.2 간단한 설명 (최대 80자)
```text
엄마 아빠 목소리로 들려주는 따뜻한 동화. 스마트폰과 태블릿을 위한 EPUB 오디오 리더.
```

### 3.3 자세한 설명 (최대 4,000자)
```text
엄마, 아빠의 따뜻한 목소리로 우리 아이에게 동화를 들려주세요.

'품속동화'는 아이가 좋아하는 동화책을 부모님이 직접 녹음한 음성과 편안한 한국어 낭독으로 언제 어디서나 즐길 수 있는 가족 중심 동화 리더 앱입니다.

■ 주요 기능
• 안전한 DRM-free EPUB 리더: DRM 없는 EPUB 동화책을 가져와 깔끔한 문단 단위로 편안하게 읽을 수 있습니다.
• 스마트폰 & 태블릿 적응형 화면: 스마트폰 세로 화면은 물론, 700dp 이상의 태블릿, 폴더블, 가로 모드에서는 조작 패널과 본문이 좌우 2열로 분할되어 최적화된 독서 환경을 제공합니다.
• 부모님 참조 목소리 녹음: 조용한 곳에서 준비된 안내 대본을 읽으며 부모님의 목소리를 녹음하고 보관할 수 있습니다.
• 한국어 TTS 문단 낭독: 기기의 기본 한국어 음성 엔진으로 원하는 문단을 바로 들을 수 있습니다.
• 읽던 위치 자동 저장: 앱을 종료했다가 다시 켜도 읽던 문단 번호가 그대로 유지되어 바로 이어 읽을 수 있습니다.

■ 철저한 개인정보 보호 및 온디바이스 원칙
• 부모님의 음성 녹음과 가져온 동화 책은 외부 서버로 업로드되지 않으며 오직 사용자의 기기 내부 안전한 영역에만 보관됩니다.
• 회원가입이나 로그인 없이 즉시 사용할 수 있습니다.
• 앱 내 광고나 타사 분석 추적기가 없어 아이들이 안심하고 사용할 수 있습니다.

■ 이용 안내
• 본 앱은 DRM이 적용되지 않은 일반 EPUB 형식의 동화 텍스트를 지원합니다.
• 목소리 녹음 기능을 사용하려면 마이크 권한 허용 및 보호자 동의가 필요합니다.
```

## 4. 그래픽 애셋 요구사항

Play Console 등록 시 필요한 이미지 사양입니다:

1. **앱 아이콘**:
   - 규격: `512 x 512 px`
   - 포맷: 32비트 PNG (알파 채널 포함 가능)
   - 최대 크기: 1MB
2. **그래픽 이미지 (Feature Graphic)**:
   - 규격: `1024 x 500 px`
   - 포맷: JPG 또는 24비트 PNG (알파 채널 없음)
   - 최대 크기: 15MB
   - 내용: 따뜻한 동화책과 부모-자녀 일러스트 또는 앱 로고가 중앙에 배치된 배너
3. **휴대전화 스크린샷**:
   - 최소 2장, 최대 8장
   - 비율: 16:9 또는 9:16 (예: 1080 x 1920 px 또는 1080 x 2400 px)
   - 추천 스크린샷 구성:
     1) 메인 화면 (EPUB 가져오기 및 동화 리더 화면)
     2) 부모님 목소리 녹음 화면 (대본 및 녹음 버튼)
     3) 문단 낭독 중인 화면 (하이라이트 및 낭독 제어)
4. **7인치 및 10인치 태블릿 스크린샷**:
   - 각 최소 1장 이상 권장
   - 2열 분할 화면(제어판 40% + 동화 본문 60%) 캡처 이미지 등록

## 5. 앱 콘텐츠 및 정책 선언 가이드

Google Play Console 좌측 메뉴 **[앱 콘텐츠]**에서 다음 항목들을 반드시 선언해야 합니다:

### 5.1 개인정보처리방침
- URL: `https://d32.org/pumsok/privacy.html`

### 5.2 앱 액세스 권한
- 선택: **"모든 기능을 제한 없이 이용할 수 있습니다"** (별도 로그인 계정 불필요)

### 5.3 광고
- 선택: **"아니요, 앱에 광고가 포함되어 있지 않습니다"**

### 5.4 콘텐츠 등급 (IARC 설문)
- 카테고리: 유틸리티, 생산성, 통신 또는 기타 (도서/참고자료)
- 폭력성, 성적 내용, 욕설, 도박, 약물: 모두 **"아니요"**
- 결과: **전체 이용가 (PEGI 3 / Everyone)** 획득

### 5.5 타깃층 및 콘텐츠 (가족 정책 대응)
- **대상 연령 선택 옵션**:
  - **방법 A (권장 - 심사 간소화)**: 만 18세 이상 (부모/보호자가 사용하는 도구로 포지셔닝). "아동에게 매력적인 요소가 있습니까?" 질문에 "예" 선택 시 가족 정책 심사를 받게 되므로, 순수하게 부모가 아이에게 읽어주는 리더 앱으로 설명.
  - **방법 B (가족 섹션 등록 희망 시)**: 5세 이하 / 6~8세 / 9~12세 선택. Google Play 가족 정책(Designed for Families) 요구사항을 준수해야 함 (현재 광고/트래커가 없으므로 기준 충족).

### 5.6 데이터 안전 (Data Safety)
- "앱에서 지원되는 사용자 데이터 유형을 수집하거나 공유합니까?" $\rightarrow$ **"아니요"**
- 설명 메모: "앱에서 요청하는 마이크 권한은 기기 로컬에서 부모님 목소리를 녹음하기 위한 것이며, 녹음 데이터는 기기 외부로 전송되지 않습니다."

### 5.7 정부 앱 / 금융 기능
- 해당 없음 선택.

## 6. 테스트 및 출시 트랙 진행 (신규 개발자 계정 필수)

> [!WARNING]
> **2023년 11월 이후 생성된 개인 개발자 계정의 필수 규정**:
> 프로덕션(정식 출시) 전 **비공개 테스트(Closed Testing)에 최소 20명의 테스터가 등록되어 최소 14일 동안 연속으로 테스트에 참여**해야 프로덕션 신청 권한이 열립니다.

### 진행 단계:
1. **Google Play Console 앱 생성**: 앱 이름, 기본 언어, 무료 선택.
2. **내부 테스트(Internal Testing)**:
   - 빌드한 AAB 업로드 (`app-release.aab`)
   - 개발자 본인 및 팀원 기기에서 즉시 다운로드하여 동작 확인.
3. **비공개 테스트(Closed Testing)**:
   - 트랙 생성 후 테스터 20명 이상의 Google 이메일 목록 또는 Google 그룹스 추가.
   - 테스터 참여 웹 링크 / Android 링크 공유.
   - 14일간 연속 유지.
4. **프로덕션 액세스 신청**:
   - 14일 경과 후 비공개 테스트 피드백 및 앱 사용 설문 작성 후 제출.
   - Google 심사(영업일 3~7일 소요) 승인 후 프로덕션 트랙 출시.

## 7. 버전 관리 및 업데이트 절차

새로운 기능을 추가하거나 수정하여 배포할 때:

1. `app/build.gradle.kts`에서 버전 올리기:
   - `versionCode`: 1 $\rightarrow$ 2 (정수 증가)
   - `versionName`: "0.1.0" $\rightarrow$ "0.1.1" (또는 "0.2.0")
2. 빌드 실행:
   ```sh
   ./gradlew bundleRelease assembleRelease
   ```
3. 웹사이트(d32.org) 업데이트:
   - `pumsok-vX.X.X.apk` 및 `pumsok-vX.X.X.aab`를 `/srv/nas/d32.org/site/pumsok/`에 복사
   - `version.json` 갱신 (파일 크기, sha256, 릴리스 노트)
4. Google Play Console에 새 AAB 업로드 및 출시 노트 작성 후 검토 제출.
