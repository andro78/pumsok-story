# 개발 기준
Android 8 이상, Kotlin/Compose. minSdk는 설치 기준이며 복제 엔진 지원 기준과 별도다.
초기에는 로컬 책과 음성을 사용한다. 가족별 목소리 다중 등록과 Media3 재생 서비스가 다음 단계다.
EPUB은 bounded ZIP 읽기, 외부 엔티티 차단, spine 순서 추출을 사용한다.
현재 리더는 본문 텍스트 방식이며 그림·고정 레이아웃·원본 페이지 렌더링은 지원하지 않는다.
동화 그림과 텍스트 배치를 보존하는 EPUB 리더는 별도 추가해야 한다.

## 음성 엔진 검증 통과 기준
상업 이용 및 앱 내 모델 재배포 조건 확인.
ARM64 실행, 메모리, 다운로드 크기 측정.
한국어 20문장과 30분 낭독에서 속도·발열·유사도 측정.
결제 전 기기 지원 검사 및 목소리 체험 제공.
일반 TTS를 부모님 복제 음성으로 표시하지 않는다.

## 서버
Orange Pi는 계정, 가족 권한, 결제 상태, 진행률 동기화를 담당한다.
음성 생성은 사용자 기기에서 실행한다. 원본 녹음 업로드는 기본 비활성이다.
결제는 Play Billing 서버 검증과 구독 복구를 구현한 후 활성화한다.
